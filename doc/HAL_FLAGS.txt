JaszczurHAL compile-time configuration
======================================

Optional functionality uses presence-based `HAL_ENABLE_*` flags. Define the
features requested by an application in `hal_project_config.h`, preferably as
plain `#define HAL_ENABLE_X` declarations. `-DHAL_ENABLE_X` is supported for
build-system integration. Do not use `HAL_ENABLE_X=0`; leave a symbol undefined
to disable it.

The versioned JSON documents in `config/features/` are the single registry for
feature names and unconditional dependencies. They generate:

- `src/hal/generated/jh_hal_features.h` for C/C++ preprocessing;
- `cmake/generated/jh_hal_features.cmake` for build source selection.

`src/hal/core/hal_config.h` is the public configuration facade. It loads the
project header, applies the generated dependency graph, and validates
target-dependent providers, board capabilities, tunables, storage layout, and
conditional choices that cannot be expressed by the registry.

The maintained public catalog, dependency overview, target selection rules,
configuration examples, and diagnostics are in:

- `doc/api/en/02_module_flags.md`;
- `config/features/README.md`;
- `doc/en/boards_profiles_howto.md`.

Command routing uses five public opt-ins. `HAL_ENABLE_COMMAND_ROUTER` selects
the transport-neutral router and versioned wire messages.
`HAL_ENABLE_LORA_COMMANDS` adds the reliable-LoRa adapter and propagates the
router plus `HAL_ENABLE_LORA_LINK`. `HAL_ENABLE_BLE_COMMANDS` adds the
authenticated BLE Stream adapter and propagates the router plus
`HAL_ENABLE_BLE_STREAM`. `HAL_ENABLE_SERIAL_COMMANDS` adds synchronous
TEXT/JSON dispatch for framed Serial Session payloads and propagates the
router. `HAL_ENABLE_NET_COMMANDS` adds the HTTP/WebSocket text/JSON adapter and
also propagates the router. BLE Stream selected alone remains a general byte
stream.

Use the shared generator runner after changing the feature or board registry:

    python3 scripts/sync_generated.py --write
    python3 scripts/sync_generated.py --check

`HAL_CONFIG_VERBOSE` reports the final active registered flags after generated
and contextual propagation. `HAL_DISABLE_ASSERTS` is the compatibility opt-out
for assertions; assertions are enabled by default.
