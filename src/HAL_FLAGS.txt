JaszczurHAL compile-time flags
==============================

All optional functionality is gated by `HAL_ENABLE_*` macros that follow an
OPT-IN model: by default *no* optional module is compiled in. To use a
module, define its `HAL_ENABLE_*` flag either:

- in your sketch's `hal_project_config.h` (auto-included via __has_include),
  e.g. `#define HAL_ENABLE_WIFI`, or
- as a compiler define, e.g. `-DHAL_ENABLE_WIFI`.

Dependency propagation is automatic. Enabling a leaf module also enables every
module it depends on; you only need to list the modules you actually use.

The only opt-OUT flag is `HAL_DISABLE_ASSERTS`, kept for compatibility with
the standard NDEBUG / assert.h convention. HAL_ASSERT() is ON by default.


Target (backend) selection
---------------------------

Separate from the per-module HAL_ENABLE_* flags, JaszczurHAL selects exactly
one hardware backend via a single switch (see src/hal/hal_target.h). Define ONE
of the following in your `hal_project_config.h` (or via -D):

    HAL_TARGET_RP2040       Raspberry Pi RP2040 / arduino-pico
    HAL_TARGET_STM32G474    STM32G474 (bare-metal backend)
    HAL_TARGET_MOCK         host unit-test / simulation backend

If you define none, the target is AUTO-DETECTED from the toolchain, so existing
projects need no change:

    arduino-pico / RP2040 SDK   -> HAL_TARGET_RP2040
    STM32G474xx (CubeG4 / -D)   -> HAL_TARGET_STM32G474
    any host compiler           -> HAL_TARGET_MOCK
    bare-metal ARM, no match    -> compile-time #error (real misconfiguration)

Selecting two targets at once is a compile-time #error. The rest of the library
tests `HAL_TARGET_IS_RP2040 / _IS_STM32G474 / _IS_MOCK` and the string
`HAL_TARGET_NAME`. Backend implementation files compile only for their own
target, so unused backends cost zero code.


Application entry flags
-----------------------

  HAL_ENABLE_APP_TASK1
    Dispatch optional app_task1() from the HAL-provided entry path. On RP2040,
    this emits Arduino loop1(), which starts the core-1 path. On STM32G474
    FreeRTOS entry builds, this creates the second application task. Leave it
    undefined for single-loop/single-task applications.


FreeRTOS integration flag
-------------------------

  HAL_ENABLE_FREERTOS
    Opt in to native FreeRTOS availability. This does not add a public
    hal_rtos_* wrapper; applications include and use native FreeRTOS headers
    directly. Current validation/build support is staged by target:

      RP2040:
        Requires arduino-pico FreeRTOS mode so __FREERTOS is defined
        (board menu "Operating System -> FreeRTOS SMP", or an equivalent
        FQBN option such as os=freertos). scripts/build_arduino_lib.sh
        --freertos and examples -DJH_RP2040_FREERTOS=ON configure this mode.
        The local third_party/FreeRTOS-Kernel tree is not used on RP2040 with the
        Arduino backend. In HAL_ENABLE_FREERTOS + __FREERTOS builds,
        hal_mutex_* uses a FreeRTOS mutex and hal_delay_ms()/hal_idle() yield
        to the scheduler from task context. hal_critical_section_* remains a
        hard per-core interrupt mask for timing-sensitive code. arduino-pico
        owns scheduler startup and HAL app_task1() dispatch is represented by
        loop1() only when HAL_ENABLE_APP_TASK1 is defined.

      STM32G474:
        Uses the local third_party/FreeRTOS-Kernel checkout, or the path set
        with JH_FREERTOS_KERNEL_DIR. scripts/ensure_freertos_kernel.sh reads
        freertos_core_version.conf and fetches/verifies the pinned upstream
        kernel ref before STM32 FreeRTOS CMake configuration needs sources.
        STM32 CMake builds compile an explicit kernel source list
        (tasks/queue/list/timers/event_groups/stream_buffer, ARM_CM4F port.c,
        heap_4.c), add the target FreeRTOSConfig.h include directory, and hand
        SVC/PendSV/SysTick vector ownership to the FreeRTOS port. hal_mutex_*
        uses a FreeRTOS mutex,
        hal_delay_ms() blocks with vTaskDelay() from legal task context, and
        hal_idle() yields to the scheduler from legal task context. Fallback
        delays remain available before the scheduler and from ISR/critical
        contexts. With HAL_PROVIDE_APP_ENTRY, HAL calls app_start(), creates
        app_task0() and optional app_task1() FreeRTOS tasks, then starts the
        scheduler.

        HAL-provided STM32 entry task defaults can be overridden with:
          HAL_FREERTOS_TASK0_STACK      default 512 FreeRTOS stack words
          HAL_FREERTOS_TASK1_STACK      default 512 FreeRTOS stack words
          HAL_FREERTOS_TASK0_PRIORITY   default tskIDLE_PRIORITY + 1
          HAL_FREERTOS_TASK1_PRIORITY   default tskIDLE_PRIORITY + 1

        Platform stack-size overrides:
          HAL_STM32_MAIN_STACK_SIZE     bytes; overrides STM32 linker
                                        _Min_Stack_Size reserve (default 0x800)
          HAL_RP2040_STACK_SIZE         bytes; mapped to PICO_STACK_SIZE
                                        (core0 stack reservation)
          HAL_RP2040_CORE1_STACK_SIZE   bytes; mapped to
                                        PICO_CORE1_STACK_SIZE

	    Full module task-safety remains conservative. Singleton/per-bus mutex
	    creation uses atomic create-once fallbacks where defensive lazy creation is
	    still needed; timer callback context, Arduino-origin wrapper internals, and
	    documented single-owner modules follow the FreeRTOS plan and thread-safety
	    audit. The normal mock backend does not support HAL_ENABLE_FREERTOS, but
	    runalltests.sh enables the host FreeRTOS POSIX scheduler test target
	    (JH_ENABLE_FREERTOS_POSIX_TESTS) to cover the FreeRTOS HAL mutex/delay and
	    lazy create-once paths in ctest without hardware.


Module enable flags
-------------------

Connectivity
  HAL_ENABLE_WIFI
    WiFi (arduino-pico; use a WiFi-capable board/FQBN such as rpipicow).
  HAL_ENABLE_TIME
    NTP / system time. Propagates: WIFI.
  HAL_ENABLE_MQTT
    PubSubClient wrapper. Propagates: WIFI.
  HAL_ENABLE_UDP
    Thread-safe WiFiUDP wrapper. Propagates: WIFI.
  HAL_ENABLE_OTA
    ArduinoOTA wrapper. Propagates: WIFI.
  HAL_ENABLE_WIREGUARD
    arduino-wireguard-pico-w wrapper. Propagates: WIFI.
  HAL_ENABLE_CELLULAR_MODEM
    Generic AT-command engine (hal_modem_at) for cellular / serial-AT
    modems. Requires at least one backend (e.g. HAL_ENABLE_A7670),
    otherwise a compile-time #error is emitted.
  HAL_ENABLE_A7670
    SimCom A7670 LTE Cat-1 cellular modem backend.
    Propagates: CELLULAR_MODEM, UART.

Storage
  HAL_ENABLE_EEPROM
    EEPROM (AT24C256 / target flash).
  HAL_ENABLE_KV
    Key-value store. Propagates: EEPROM.
  HAL_ENABLE_LITTLEFS
    LittleFS lifecycle and basic filesystem helpers. On STM32G474 this uses
    an internal flash partition controlled by HAL_STM32_FLASH_LITTLEFS_SIZE.
  HAL_ENABLE_SDLOGGER
    SD-card logger and crash-report logger. Propagates: EEPROM, I2C, SPI.

Buses
  HAL_ENABLE_UART          Hardware UART (SerialUART).
  HAL_ENABLE_SWSERIAL      SoftwareSerial.
  HAL_ENABLE_I2C           I2C master (Wire).
  HAL_ENABLE_I2C_SLAVE     I2C slave / target mode with register map.
  HAL_ENABLE_SPI           SPI master (Arduino-compatible SPIClass).
  HAL_ENABLE_CAN           Generic CAN API facade.
  HAL_ENABLE_MCP2515       MCP2515 CAN backend. Propagates: CAN, SPI.
  HAL_ENABLE_MCP251XFD     MCP2517FD/MCP2518FD CAN FD backend. Propagates: CAN, SPI.
  HAL_ENABLE_STM32G474_FDCAN
    Native STM32G474 FDCAN1 backend. Propagates: CAN. Requires
    HAL_TARGET_STM32G474 and is rejected on all other targets.

Time-of-day (RTC)
  HAL_ENABLE_RTC
    Generic RTC API. Requires at least one backend below, otherwise a
    compile-time #error is emitted.
  HAL_ENABLE_PCF8563       PCF8563 backend. Propagates: RTC, I2C.
  HAL_ENABLE_DS3231        DS3231 backend.  Propagates: RTC, I2C.

Sensors
  HAL_ENABLE_THERMOCOUPLE
    Generic thermocouple API. Requires at least one backend below.
  HAL_ENABLE_MCP9600       MCP9600/MCP9601 shared HAL I2C driver.
                           Propagates: THERMOCOUPLE, I2C.
  HAL_ENABLE_MAX6675       MAX6675 bit-bang over HAL GPIO.
                           Propagates: THERMOCOUPLE.
  HAL_ENABLE_DS18B20       Shared DS18B20 1-Wire temperature. Propagates: ONEWIRE.
  HAL_ENABLE_BH1750        Shared BH1750 ambient-light sensor over HAL I2C.
                           Propagates: I2C.
  HAL_ENABLE_TSC2007       Shared TSC2007 resistive touch controller over HAL I2C.
                           Propagates: I2C.
  HAL_ENABLE_STMPE610      Shared STMPE610 resistive touch controller over HAL
                           I2C/SPI. Propagates: I2C, SPI.
  HAL_ENABLE_IRSMALL_DECODER
                           Shared IR receiver decoder over HAL GPIO
                           interrupts and system timing.
  HAL_ENABLE_ONEWIRE       Shared generic 1-Wire bus API wrapper.
  HAL_ENABLE_EXTERNAL_ADC  ADS1115 external ADC via shared ADS1X15 HAL I2C driver.
                           Propagates: I2C.
  HAL_ENABLE_GPS           Portable NMEA receiver. Backend-agnostic engine
                           (RP2040 + STM32G474); decodes position, altitude,
                           course, speed, date/time, fix quality/mode, DOPs,
                           satellites used/in-view and GST accuracy. Needs a
                           transport: HAL_ENABLE_SWSERIAL or HAL_ENABLE_UART.
                           If neither is selected, HAL auto-enables UART.

Digital potentiometers
  HAL_ENABLE_DIGIPOT
    Generic digital-potentiometer API. Requires at least one backend below.
  HAL_ENABLE_MCP401X       MCP4017/4018/4019 (I2C 0x2F, 128 taps).
                           Propagates: DIGIPOT, I2C.
  HAL_ENABLE_MAX5395       MAX5395 (I2C 0x28/0x29/0x2B, 256 taps).
                           Propagates: DIGIPOT, I2C.
                           Backend-agnostic: one source over hal_i2c, runs on
                           RP2040 and STM32G474 alike.

Audio volume control
  HAL_ENABLE_PGA2311       PGA2311 stereo volume controller over HAL SPI/GPIO.
                           Propagates: SPI.

Analog out / status
  HAL_ENABLE_DAC           True DAC output. Real on STM32G474 (DAC1, 12-bit,
                           PA4/PA5); reported unsupported on RP2040 (no DAC) -
                           check hal_dac_is_supported().
  HAL_ENABLE_PWM_FREQ      Frequency-controlled PWM.
  HAL_ENABLE_RGB_LED       NeoPixel RGB status LED.

Counters
  HAL_ENABLE_PCNT          Edge / pulse counter. STM32G474: hardware timer
                           (TIM2 ext-clock, ch0 = PA0). RP2040: software counter
                           via a GPIO edge interrupt (ISR-rate limited).

Display
  HAL_ENABLE_HD44780 HD44780-compatible parallel character LCD driver
                           over HAL GPIO/system timing.
  HAL_ENABLE_DISPLAY
    Generic display API. Requires at least one of TFT or SSD1306.
  HAL_ENABLE_TFT
    SPI TFT family fasada. Requires at least one of the four drivers
    below. Propagates: DISPLAY, SPI.
  HAL_ENABLE_ILI9341       ILI9341 driver over the shared HAL SPI/GPIO core
                           and GFX engine. Propagates: TFT, DISPLAY, SPI.
  HAL_ENABLE_ST7789        ST7789  driver over the shared ST77xx HAL SPI/GPIO
                           core and GFX engine. Propagates: TFT, DISPLAY, SPI.
  HAL_ENABLE_ST7735        ST7735  driver over the shared ST77xx HAL SPI/GPIO
                           core and GFX engine. Propagates: TFT, DISPLAY, SPI.
  HAL_ENABLE_ST7796S       ST7796S driver over the shared ST77xx HAL SPI/GPIO
                           core and GFX engine. Propagates: TFT, DISPLAY, SPI.
  HAL_ENABLE_SSD1306       SSD1306 OLED over the shared HAL I2C driver and GFX
                           engine. Propagates: DISPLAY, I2C.

Crypto / bundled libs
  HAL_ENABLE_CRYPTO
    hal_crypto (Base64, MD5, SHA-256, HMAC-SHA256, ChaCha20 / -Poly1305)
    with ChaCha20/Poly1305 delegated to the shared wireguard/crypto backend.
    plus the dependent hal_sc_auth helper. Without this flag the headers
    expand to nothing and the implementation TUs produce empty objects.
    hal_serial_session keeps working - the SC_AUTH_BEGIN / SC_AUTH_PROVE
    handlers are simply compiled out and the session never enters the
    authenticated state.
  HAL_ENABLE_CJSON
    Bundled cJSON / cJSON_Utils sources.
  HAL_ENABLE_PNG
    Bundled LodePNG memory-based PNG encoder/decoder. JaszczurHAL disables
    LodePNG disk helpers and the C++ std wrapper by default; define
    HAL_LODEPNG_ENABLE_DISK or HAL_LODEPNG_ENABLE_CPP to opt them back in.
  HAL_ENABLE_PNG_AS_BASE64
    Base64-encoded PNG helpers in tools. Propagates: CRYPTO, PNG.

Test framework
  HAL_ENABLE_UNITY
    Bundled Unity framework. Typically enabled only by the host-test
    CMake (root CMakeLists.txt).


Opt-out flags
-------------

  HAL_DISABLE_ASSERTS
    Compile every HAL_ASSERT() to a no-op (zero text / branch in release).
    Asserts are ON by default. Mirrors the standard NDEBUG convention.


Debug
-----

  HAL_CONFIG_VERBOSE
    Make the preprocessor emit a `#pragma message` for every HAL_ENABLE_*
    flag that is active after propagation. Useful for diagnosing "why is
    module X being compiled in?".

Consistency checks (compile-time #error)
----------------------------------------

  HAL_ENABLE_RTC          requires HAL_ENABLE_PCF8563 OR HAL_ENABLE_DS3231
  HAL_ENABLE_CELLULAR_MODEM requires HAL_ENABLE_A7670
  HAL_ENABLE_THERMOCOUPLE requires HAL_ENABLE_MCP9600 OR HAL_ENABLE_MAX6675
  HAL_ENABLE_DIGIPOT      requires HAL_ENABLE_MCP401X OR HAL_ENABLE_MAX5395
  HAL_ENABLE_GPS          requires HAL_ENABLE_SWSERIAL OR HAL_ENABLE_UART
  HAL_ENABLE_DISPLAY      requires HAL_ENABLE_TFT     OR HAL_ENABLE_SSD1306
  HAL_ENABLE_TFT          requires HAL_ENABLE_ILI9341 / ST7789 / ST7735 / ST7796S
