JaszczurHAL compile-time flags
==============================

All optional functionality is gated by `HAL_ENABLE_*` macros that follow an
OPT-IN model: by default *no* optional module is compiled in. To use a
module, define its `HAL_ENABLE_*` flag either:

- in your sketch's `hal_project_config.h` (auto-included via __has_include),
  e.g. `#define HAL_ENABLE_WIFI`, or
- as a compiler define, e.g. `-DHAL_ENABLE_WIFI`.

Dependency propagation is automatic. Enabling a leaf module also enables every
module it depends on; you only need to list the modules you actually use.

The only opt-OUT flag is `HAL_DISABLE_ASSERTS`, kept for compatibility with
the standard NDEBUG / assert.h convention. HAL_ASSERT() is ON by default.


Module enable flags
-------------------

Connectivity
  HAL_ENABLE_WIFI
    WiFi (arduino-pico, requires PICO_W to be useful at runtime).
  HAL_ENABLE_TIME
    NTP / system time. Propagates: WIFI.
  HAL_ENABLE_MQTT
    PubSubClient wrapper. Propagates: WIFI.
  HAL_ENABLE_UDP
    Thread-safe WiFiUDP wrapper. Propagates: WIFI.
  HAL_ENABLE_OTA
    ArduinoOTA wrapper. Propagates: WIFI.
  HAL_ENABLE_WIREGUARD
    arduino-wireguard-pico-w wrapper. Propagates: WIFI.

Storage
  HAL_ENABLE_EEPROM
    EEPROM (AT24C256 / RP2040 flash).
  HAL_ENABLE_KV
    Key-value store. Propagates: EEPROM.
  HAL_ENABLE_LITTLEFS
    LittleFS lifecycle and basic filesystem helpers.

Buses
  HAL_ENABLE_UART          Hardware UART (SerialUART).
  HAL_ENABLE_SWSERIAL      SoftwareSerial.
  HAL_ENABLE_I2C           I2C master (Wire).
  HAL_ENABLE_I2C_SLAVE     I2C slave / target mode with register map.
  HAL_ENABLE_CAN           MCP2515 CAN bus.

Time-of-day (RTC)
  HAL_ENABLE_RTC
    Generic RTC API. Requires at least one backend below, otherwise a
    compile-time #error is emitted.
  HAL_ENABLE_PCF8563       PCF8563 backend. Propagates: RTC, I2C.
  HAL_ENABLE_DS3231        DS3231 backend.  Propagates: RTC, I2C.

Sensors
  HAL_ENABLE_THERMOCOUPLE
    Generic thermocouple API. Requires at least one backend below.
  HAL_ENABLE_MCP9600       MCP9600/MCP9601. Propagates: THERMOCOUPLE, I2C.
  HAL_ENABLE_MAX6675       MAX6675 SPI.     Propagates: THERMOCOUPLE.
  HAL_ENABLE_DS18B20       DS18B20 1-Wire temperature. Propagates: ONEWIRE.
  HAL_ENABLE_ONEWIRE       Generic 1-Wire bus API wrapper.
  HAL_ENABLE_EXTERNAL_ADC  ADS1115 external ADC. Propagates: I2C.
  HAL_ENABLE_GPS           TinyGPS++ NMEA parser. Propagates: SWSERIAL.

PWM / status
  HAL_ENABLE_PWM_FREQ      Frequency-controlled PWM.
  HAL_ENABLE_RGB_LED       NeoPixel RGB status LED.

Display
  HAL_ENABLE_DISPLAY
    Generic display API. Requires at least one of TFT or SSD1306.
  HAL_ENABLE_TFT
    SPI TFT family fasada. Requires at least one of the four drivers
    below. Propagates: DISPLAY.
  HAL_ENABLE_ILI9341       ILI9341 driver. Propagates: TFT, DISPLAY.
  HAL_ENABLE_ST7789        ST7789  driver. Propagates: TFT, DISPLAY.
  HAL_ENABLE_ST7735        ST7735  driver. Propagates: TFT, DISPLAY.
  HAL_ENABLE_ST7796S       ST7796S driver. Propagates: TFT, DISPLAY.
  HAL_ENABLE_SSD1306       SSD1306 OLED.   Propagates: DISPLAY.

Crypto / bundled libs
  HAL_ENABLE_CRYPTO
    hal_crypto (Base64, MD5, SHA-256, HMAC-SHA256, ChaCha20 / -Poly1305)
    plus the dependent hal_sc_auth helper. Without this flag the headers
    expand to nothing and the implementation TUs produce empty objects.
    hal_serial_session keeps working - the SC_AUTH_BEGIN / SC_AUTH_PROVE
    handlers are simply compiled out and the session never enters the
    authenticated state.
  HAL_ENABLE_CJSON
    Bundled cJSON / cJSON_Utils sources.

Test framework
  HAL_ENABLE_UNITY
    Bundled Unity framework. Typically enabled only by the host-test
    CMake (root CMakeLists.txt).


Opt-out flags
-------------

  HAL_DISABLE_ASSERTS
    Compile every HAL_ASSERT() to a no-op (zero text / branch in release).
    Asserts are ON by default. Mirrors the standard NDEBUG convention.


Debug
-----

  HAL_CONFIG_VERBOSE
    Make the preprocessor emit a `#pragma message` for every HAL_ENABLE_*
    flag that is active after propagation. Useful for diagnosing "why is
    module X being compiled in?".

Consistency checks (compile-time #error)
----------------------------------------

  HAL_ENABLE_RTC          requires HAL_ENABLE_PCF8563 OR HAL_ENABLE_DS3231
  HAL_ENABLE_THERMOCOUPLE requires HAL_ENABLE_MCP9600 OR HAL_ENABLE_MAX6675
  HAL_ENABLE_DISPLAY      requires HAL_ENABLE_TFT     OR HAL_ENABLE_SSD1306
  HAL_ENABLE_TFT          requires HAL_ENABLE_ILI9341 / ST7789 / ST7735 / ST7796S
