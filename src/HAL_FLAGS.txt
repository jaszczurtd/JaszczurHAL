JaszczurHAL compile-time flags
==============================

All optional functionality is gated by `HAL_ENABLE_*` macros that follow an
OPT-IN model: by default *no* optional module is compiled in. To use a
module, define its `HAL_ENABLE_*` flag either:

- in your sketch's `hal_project_config.h` (auto-included via __has_include),
  e.g. `#define HAL_ENABLE_WIFI`, or
- as a compiler define, e.g. `-DHAL_ENABLE_WIFI`.

Dependency propagation is automatic. Enabling a leaf module also enables every
module it depends on; you only need to list the modules you actually use.

The only opt-OUT flag is `HAL_DISABLE_ASSERTS`, kept for compatibility with
the standard NDEBUG / assert.h convention. HAL_ASSERT() is ON by default.


Target (backend) selection
---------------------------

Separate from the per-module HAL_ENABLE_* flags, JaszczurHAL selects exactly
one hardware backend via a single switch (see src/hal/hal_target.h). Define ONE
of the following in your `hal_project_config.h` (or via -D):

    HAL_TARGET_RP2040       Raspberry Pi RP2040 / arduino-pico
    HAL_TARGET_STM32G474    STM32G474 (bare-metal backend)
    HAL_TARGET_MOCK         host unit-test / simulation backend

If you define none, the target is AUTO-DETECTED from the toolchain, so existing
projects need no change:

    arduino-pico / RP2040 SDK   -> HAL_TARGET_RP2040
    STM32G474xx (CubeG4 / -D)   -> HAL_TARGET_STM32G474
    any host compiler           -> HAL_TARGET_MOCK
    bare-metal ARM, no match    -> compile-time #error (real misconfiguration)

Selecting two targets at once is a compile-time #error. The rest of the library
tests `HAL_TARGET_IS_RP2040 / _IS_STM32G474 / _IS_MOCK` and the string
`HAL_TARGET_NAME`. Backend implementation files compile only for their own
target, so unused backends cost zero code.


Module enable flags
-------------------

Connectivity
  HAL_ENABLE_WIFI
    WiFi (arduino-pico; use a WiFi-capable board/FQBN such as rpipicow).
  HAL_ENABLE_TIME
    NTP / system time. Propagates: WIFI.
  HAL_ENABLE_MQTT
    PubSubClient wrapper. Propagates: WIFI.
  HAL_ENABLE_UDP
    Thread-safe WiFiUDP wrapper. Propagates: WIFI.
  HAL_ENABLE_OTA
    ArduinoOTA wrapper. Propagates: WIFI.
  HAL_ENABLE_WIREGUARD
    arduino-wireguard-pico-w wrapper. Propagates: WIFI.
  HAL_ENABLE_CELLULAR_MODEM
    Generic AT-command engine (hal_modem_at) for cellular / serial-AT
    modems. Requires at least one backend (e.g. HAL_ENABLE_A7670),
    otherwise a compile-time #error is emitted.
  HAL_ENABLE_A7670
    SimCom A7670 LTE Cat-1 cellular modem backend.
    Propagates: CELLULAR_MODEM, UART.

Storage
  HAL_ENABLE_EEPROM
    EEPROM (AT24C256 / RP2040 flash).
  HAL_ENABLE_KV
    Key-value store. Propagates: EEPROM.
  HAL_ENABLE_LITTLEFS
    LittleFS lifecycle and basic filesystem helpers.
  HAL_ENABLE_SDLOGGER
    SD-card logger and crash-report logger. Propagates: EEPROM, I2C, SPI.

Buses
  HAL_ENABLE_UART          Hardware UART (SerialUART).
  HAL_ENABLE_SWSERIAL      SoftwareSerial.
  HAL_ENABLE_I2C           I2C master (Wire).
  HAL_ENABLE_I2C_SLAVE     I2C slave / target mode with register map.
  HAL_ENABLE_SPI           SPI master (Arduino-compatible SPIClass).
  HAL_ENABLE_CAN           MCP2515 CAN bus. Propagates: SPI.

Time-of-day (RTC)
  HAL_ENABLE_RTC
    Generic RTC API. Requires at least one backend below, otherwise a
    compile-time #error is emitted.
  HAL_ENABLE_PCF8563       PCF8563 backend. Propagates: RTC, I2C.
  HAL_ENABLE_DS3231        DS3231 backend.  Propagates: RTC, I2C.

Sensors
  HAL_ENABLE_THERMOCOUPLE
    Generic thermocouple API. Requires at least one backend below.
  HAL_ENABLE_MCP9600       MCP9600/MCP9601 shared HAL I2C driver.
                           Propagates: THERMOCOUPLE, I2C.
  HAL_ENABLE_MAX6675       MAX6675 bit-bang over HAL GPIO.
                           Propagates: THERMOCOUPLE.
  HAL_ENABLE_DS18B20       DS18B20 1-Wire temperature. Propagates: ONEWIRE.
  HAL_ENABLE_ONEWIRE       Generic 1-Wire bus API wrapper.
  HAL_ENABLE_EXTERNAL_ADC  ADS1115 external ADC. Propagates: I2C.
  HAL_ENABLE_GPS           Portable NMEA receiver. Backend-agnostic engine
                           (RP2040 + STM32G474); decodes position, altitude,
                           course, speed, date/time, fix quality/mode, DOPs,
                           satellites used/in-view and GST accuracy. Needs a
                           transport: HAL_ENABLE_SWSERIAL or HAL_ENABLE_UART
                           (does NOT auto-enable one).

Digital potentiometers
  HAL_ENABLE_DIGIPOT
    Generic digital-potentiometer API. Requires at least one backend below.
  HAL_ENABLE_MCP401X       MCP4017/4018/4019 (I2C 0x2F, 128 taps).
                           Propagates: DIGIPOT, I2C.
  HAL_ENABLE_MAX5395       MAX5395 (I2C 0x28/0x29/0x2B, 256 taps).
                           Propagates: DIGIPOT, I2C.
                           Backend-agnostic: one source over hal_i2c, runs on
                           RP2040 and STM32G474 alike.

Analog out / status
  HAL_ENABLE_DAC           True DAC output. Real on STM32G474 (DAC1, 12-bit,
                           PA4/PA5); reported unsupported on RP2040 (no DAC) -
                           check hal_dac_is_supported().
  HAL_ENABLE_PWM_FREQ      Frequency-controlled PWM.
  HAL_ENABLE_RGB_LED       NeoPixel RGB status LED.

Counters
  HAL_ENABLE_PCNT          Edge / pulse counter. STM32G474: hardware timer
                           (TIM2 ext-clock, ch0 = PA0). RP2040: software counter
                           via a GPIO edge interrupt (ISR-rate limited).

Display
  HAL_ENABLE_DISPLAY
    Generic display API. Requires at least one of TFT or SSD1306.
  HAL_ENABLE_TFT
    SPI TFT family fasada. Requires at least one of the four drivers
    below. Propagates: DISPLAY, SPI.
  HAL_ENABLE_ILI9341       ILI9341 driver. Propagates: TFT, DISPLAY, SPI.
  HAL_ENABLE_ST7789        ST7789  driver. Propagates: TFT, DISPLAY, SPI.
  HAL_ENABLE_ST7735        ST7735  driver. Propagates: TFT, DISPLAY, SPI.
  HAL_ENABLE_ST7796S       ST7796S driver. Propagates: TFT, DISPLAY, SPI.
  HAL_ENABLE_SSD1306       SSD1306 OLED.   Propagates: DISPLAY.

Crypto / bundled libs
  HAL_ENABLE_CRYPTO
    hal_crypto (Base64, MD5, SHA-256, HMAC-SHA256, ChaCha20 / -Poly1305)
    plus the dependent hal_sc_auth helper. Without this flag the headers
    expand to nothing and the implementation TUs produce empty objects.
    hal_serial_session keeps working - the SC_AUTH_BEGIN / SC_AUTH_PROVE
    handlers are simply compiled out and the session never enters the
    authenticated state.
  HAL_ENABLE_CJSON
    Bundled cJSON / cJSON_Utils sources.

Test framework
  HAL_ENABLE_UNITY
    Bundled Unity framework. Typically enabled only by the host-test
    CMake (root CMakeLists.txt).


Opt-out flags
-------------

  HAL_DISABLE_ASSERTS
    Compile every HAL_ASSERT() to a no-op (zero text / branch in release).
    Asserts are ON by default. Mirrors the standard NDEBUG convention.


Debug
-----

  HAL_CONFIG_VERBOSE
    Make the preprocessor emit a `#pragma message` for every HAL_ENABLE_*
    flag that is active after propagation. Useful for diagnosing "why is
    module X being compiled in?".

Consistency checks (compile-time #error)
----------------------------------------

  HAL_ENABLE_RTC          requires HAL_ENABLE_PCF8563 OR HAL_ENABLE_DS3231
  HAL_ENABLE_CELLULAR_MODEM requires HAL_ENABLE_A7670
  HAL_ENABLE_THERMOCOUPLE requires HAL_ENABLE_MCP9600 OR HAL_ENABLE_MAX6675
  HAL_ENABLE_DIGIPOT      requires HAL_ENABLE_MCP401X OR HAL_ENABLE_MAX5395
  HAL_ENABLE_GPS          requires HAL_ENABLE_SWSERIAL OR HAL_ENABLE_UART
  HAL_ENABLE_DISPLAY      requires HAL_ENABLE_TFT     OR HAL_ENABLE_SSD1306
  HAL_ENABLE_TFT          requires HAL_ENABLE_ILI9341 / ST7789 / ST7735 / ST7796S
